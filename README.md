# DentalTouch — 의료진용 대시보드 (CDSS Prototype)

> 치과 예진 정보 확인과 진료 업무 흐름을 지원하는 의료진용 웹 대시보드

- **개발 기간:** 2026.09.04 ~ 2026.09.20
- **프로젝트:** Wanted AI Championship 2026 / 5인 팀
- **주요 기술:** React, TypeScript, Firebase Firestore, Vercel

## 프로젝트 소개

환자가 입력한 예진 정보와 과거 진료 관련 정보를 의료진이 확인하고, 접수·예약·차팅 업무를 수행할 수 있도록 구성한 진료 지원 프로토타입입니다. 간호사·원무과와 의사의 사용 흐름을 구분했습니다.

## 주요 기능

### 간호사·원무과 화면

- 환자 기본정보, 주요 증상, 병력, 복용 약물 및 알레르기 조회
- 과거 내원 기록과 의사 차팅 내용 확인
- 의사 차팅 조회 및 인쇄 기능 제공, 수정 기능 제한
- 시스템에서 제안한 진료과를 담당자가 검토하고 재배정
- 신규 환자 접수, 진료 일정 및 후속 예약 관련 화면

### 의사용 화면

- 당일 진료 순서와 환자 목록을 확인하는 워크스테이션
- 예진 정보, 과거 내원 기록, 협진 관련 정보 조회
- 감별진단 후보 및 주의 정보의 참고용 표시
- 진료 소견·처방 등 차팅 관련 화면
- 후속 외래 일정 지정 및 원무 관리 화면 접근

> 감별진단 후보는 실제 임상적 정확성이 검증된 진단 결과가 아니라 프로토타입에서 제공하는 참고 정보입니다.

## 담당 역할

- 환자·의료진 간 업무 흐름과 주요 기능 기획
- 의료 도메인 팀원의 피드백을 반영한 화면 및 기능 요구사항 정리
- AI 코딩 도구를 활용한 의료진용 대시보드 개발 전담
- 예진 정보 표시, Red Flag 주의 정보 확인, 차트 및 예약 관련 기능 테스트
- Firestore 연동 과정의 일부 오류 해결과 반복적인 기능 개선

## 개발 방식 및 AI 사용 범위

Google AI Studio 등 AI 코딩 도구를 사용해 요구사항을 전달하고 생성된 결과를 테스트·개선했습니다. 생성된 코드 전체를 직접 작성하거나 내부 알고리즘을 모두 설계한 것은 아닙니다.

**Gemini API를 서비스 실행 중 호출하는 기능은 현재 코드에서 확인되지 않았으므로, Gemini Structured Output API 연동을 구현 성과로 기재하지 않습니다.**

## 데이터와 검증 범위

- 실제 환자 데이터가 아닌 생성형 AI 기반 가상 환자 데이터를 사용했습니다.
- 화면 동작과 업무 흐름을 시연하기 위한 프로토타입입니다.
- 실제 의료기관 EMR 연동, 임상적 정확성 검증, 의료기관 환경에서의 안정성 검증은 진행하지 않았습니다.
- Red Flag 표시 및 감별진단 후보는 의료진의 최종 판단을 대체하지 않습니다.
